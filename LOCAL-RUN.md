# Open Crownfall on your device

The localhost server in a remote workspace cannot be reached through localhost on another computer or phone.

Download this folder to your computer and unzip it. Double-click START-WINDOWS.bat on Windows, or run ./start.sh on macOS or Linux. Python 3 is required. The launcher opens the game in your browser.

You can also open index.html directly to play offline without a server.

For a phone, use a hosted game URL; localhost on a phone points to the phone itself.
